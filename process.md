1 - The following part of your input was truncated because CLIP can only handle sequences up to 77 tokens, so we changed vlm to produce in maximum 70 tokens instead of 128 (default) to maintain interpretability and avoid CLIP truncation.

2 - Initially, the VLM was called 10 times with the same system prompt and high temperature (0.9) to generate diverse candidates. However, the generated prompts were too similar to each other, converging on the same visual elements. To address this, we introduced 10 style hints, each guiding the VLM to focus on a different aspect of the image (subject, lighting, colours, composition, mood, artistic style, textures, background, contrast, and photographic style). Each candidate is generated with a different hint, ensuring the initial population covers diverse regions of the prompt space, which is critical for the subsequent OPRO and GA optimization stages.

3 - Qwen3-4B-Instruct-2507 was employed as the core LLM for the OPRO pipeline. However, this model size proved insufficient for the meta-optimization task, so we changed to Qwen2.5-7B-Instruct, to improve cognitive depth and properly navigate the prompt space based on historical feedback.

4 - During OPRO optimization, a critical issue was identified: both the VLM and OPRO were generating incomplete prompts truncated mid-sentence, as the models defaulted to long descriptive sentences that exceeded the 50 token budget. This issue was rsolved by explicitly instructing the models to generate short, complete prompts under 50 tokens with no incomplete sentences. Additionally, to prevent the OPRO from collapsing to the same prompt across iterations, explicit diversity instructions were added to the system prompt, requiring each new candidate to be different from all previous ones.

5 - A warmup period of 5 iterations was introduced before the early stopping criterion was applied. Without warmup, the OPRO would stop prematurely if the initial candidates from the VLM were already strong, preventing the LLM from exploring the prompt space. With 5 warmup iterations, the OPRO always runs at least 25 new candidate evaluations before counting iterations without improvement, giving the LLM sufficient time to learn patterns from the history and explore diverse regions of the prompt space.

6 - Analysis of the OPRO iteration revealed a critical convergence failure, despite diversity instructions in the prompt, the LLM was performing synonym substitution rather than structural exploration. Consequently, OPRO candidates never exceeded the fitness of the best VLM candidate (0.8691), as the LLM was anchoring on the single best prompt in the history and making incremental lexical changes. Two possible causes were identified : showing all 20 population candidates as context caused the LLM to fixate on the highest-scoring one, and the generic "be different" instruction was insufficient to break structural repetition. This convergence was particularly problematic for the subsequent Genetic Evolution stage, which requires a diverse initial population for crossover to produce meaningful recombinations.

7 - To address the OPRO convergence issue and improve diversity for the GE stage, the prompt strategy was redesigned in both the VLM and OPRO modules. In the VLM, the style hints were reformulated as dimension instructions: the hints now explicitly specifies which single visual dimension to describe and prohibits mentioning other dimensions. In the OPRO, the generation strategy was changed from a single generic call to one targeted call per visual dimension (subject, lighting, style, composition, mood), cycling through them each iteration. Each call receives only the top-5 highest-scoring candidates as references instead of 20, and a dimension guide specifying what to include and what to suppress. This ensures that the 5 new candidates generated per OPRO iteration are structurally distinct from each other, maintaining population diversity throughout the optimization and providing meaningful variation for the GE stage to exploit.

8 - The exclusive dimension approach produced incomplete prompts, each covering only one visual aspect. This is problematic for GA crossover: combining two incomplete parents does not reliably yield a complete offspring. The approach was changed to emphasis-based generation, each prompt covers all visual aspects but gives particular weight to one dimension. Structural diversity is preserved while every candidate remains a complete, viable prompt for the diffusion model.
