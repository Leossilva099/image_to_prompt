2- Initially, the VLM was called 10 times with the same system prompt and high temperature (0.9) to generate diverse candidates. However, the generated prompts were too similar to each other, converging on the same visual elements. To address this, we introduced 10 style hints, each guiding the VLM to focus on a different aspect of the image (subject, lighting, colours, composition, mood, artistic style, textures, background, contrast, and photographic style). Each candidate is generated with a different hint, ensuring the initial population covers diverse regions of the prompt space, which is critical for the subsequent OPRO and GA optimization stages.

3- Qwen3-4B-Instruct-2507 was employed as the core LLM for the OPRO pipeline. However, this model size proved insufficient for the meta-optimization task, so we changed to Qwen2.5-7B-Instruct, to improve cognitive depth and properly navigate the prompt space based on historical feedback.

4- During OPRO optimization, a critical issue was identified: both the VLM and OPRO were generating incomplete prompts truncated mid-sentence, as the models defaulted to long descriptive sentences that exceeded the 50 token budget. This issue was rsolved by explicitly instructing the models to generate short, complete prompts under 50 tokens with no incomplete sentences. Additionally, to prevent the OPRO from collapsing to the same prompt across iterations, explicit diversity instructions were added to the system prompt, requiring each new candidate to be different from all previous ones.

5- A warmup period of 5 iterations was introduced before the early stopping criterion was applied. Without warmup, the OPRO would stop prematurely if the initial candidates from the VLM were already strong, preventing the LLM from exploring the prompt space. With 5 warmup iterations, the OPRO always runs at least 25 new candidate evaluations before counting iterations without improvement, giving the LLM sufficient time to learn patterns from the history and explore diverse regions of the prompt space.
